# Day 7 — Final review, submit, prepare presentation

## Submission checklist
- [ ] Final report roughly **10–12 pages** for an exploration project, APA compliant.
- [ ] Introduction, research question/hypothesis, methodology, actual results, lessons learned and recommendations included.
- [ ] Correct title page, headings, references and citations under your instructor's APA instructions.
- [ ] Figures labeled; sensitive data redacted.
- [ ] The report reflects the **real** Ubuntu version, DigitalOcean setup, commands, and observations.
- [ ] All required files uploaded to Canvas according to actual current due date.

## Presentation (10–15 min + Q&A)
Suggested 8–10 slides:
1. Title / question (1 min)
2. Threats and security objectives (1 min)
3. Droplet environment and method (1–2 min)
4. Initial baseline (1 min)
5. SSH prevention (1–2 min)
6. UFW + Cloud Firewall prevention (1 min)
7. Fail2ban and logs (1–2 min)
8. Before/after results (2 min)
9. Limitations and lessons learned (1 min)
10. Conclusion / Q&A

Consider a **recorded or screenshot-based demo** in case the live server or network is unavailable during class. Don't show a live private key or public IPs if unnecessary.

## Server cleanup / cost control
After grading and evidence capture, decide whether you need the server. If not, delete the Droplet and optional billable backups/snapshots deliberately; simply powering off a Droplet generally does **not** stop all charges. Keep your sanitized local research evidence.
