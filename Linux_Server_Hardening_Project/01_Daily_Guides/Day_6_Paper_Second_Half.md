# Day 6 — Finish results, discussion, and references

**Target:** Complete the ~10–12-page exploration report; confirm with instructor whether references/figures count toward page length.

## Sections
1. **Implementation / results (~2–3 pages)** — Before/after table, key configuration evidence, Lynis observations, Fail2ban activity (or absence thereof), update status.
2. **Discussion (~1 page)** — Which controls prevent access vs. detect activity? Which did you verify directly? What remains uncertain?
3. **Limitations and lessons (~0.5–1 page)** — Short timeframe, one host, limited testing, cloud provider controls, trade-offs and troubleshooting.
4. **Conclusion (~0.5 page)** — Answer the research question without overstating the findings.
5. **References** — Complete APA citations; verify URLs, titles, dates, authors and in-text citations.

## Checks
- [ ] Every measured value matches your evidence template.
- [ ] No made-up failed-login counts, scans, warnings, or score gains.
- [ ] Never describe passive observations as a controlled causal experiment.
- [ ] State the before/after scores and what changed; explain why score changes do not prove complete security.
