# Day 5 — Write the first half of the APA paper

**Target:** Draft ~5–6 pages using your *actual observations*. Follow the assignment sheet and instructor's APA preferences.

## Writing sequence
1. **Introduction (~1 page)** — Why Linux server hardening matters, the research question, scope, and hypothesis.
2. **Background (~2 pages)** — Explain SSH, key authentication, firewall layers, Fail2ban, and configuration auditing. Use credible sources and citations.
3. **Methods (~2 pages)** — What Droplet and OS you used, when you ran the baseline, exact changes, how you verified them, and what evidence you recorded.

## Checklist
- [ ] Describe whether the new Droplet already had SSH keys or provider firewall security in place.
- [ ] Explain that the work was limited to your own server and passive monitoring; any active demonstrations were isolated locally.
- [ ] Distinguish **observations** from assumptions or expectations.
- [ ] Insert figures/screenshots with captions if your instructor permits them; redact IPs/hostnames and names when needed.
- [ ] Cite vendor docs for product behavior; use scholarly or authoritative security material for broader claims as appropriate.
- [ ] Keep a record of every source you cite.
