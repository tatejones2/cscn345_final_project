## Citation practice
- In the paper, distinguish facts learned from the sources from *your own* settings and measured results.
- Do not cite the course guide as proof of a technical security claim; use it only for assignment requirements.
- Do not cite a webpage you didn't read or copy a sample reference without verifying it.
- Record access dates where appropriate and follow your professor's APA version instructions.
