# Evidence Organization and Screenshot Checklist

Create a local folder `evidence/` (do not commit it publicly). Suggested names:

- `day1-ubuntu-version.png`
- `day1-sshd-effective-settings.png`
- `day1-ufw-before.png`
- `day1-lynis-before.png`
- `day2-sshd-after.png`
- `day2-key-login.png`
- `day2-password-only-rejected.png`
- `day2-ufw-after.png`
- `day2-cloud-firewall.png`
- `day3-fail2ban-jail.png`
- `day3-auth-logs-redacted.png`
- `day3-updates-config.png`
- `day4-lynis-after.png`
- `day4-verified-controls.png`

Each screenshot or output should have **date, command/context, what it demonstrates**, and a corresponding reference in your methods or results notes.

**Privacy:** Redact public IP addresses (including third-party IPs in logs if unnecessary), tokens, user names and identifying server labels. Never include secret SSH keys or account recovery details.
